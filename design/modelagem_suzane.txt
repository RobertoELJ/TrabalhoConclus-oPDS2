USER STORIES (ESTOQUE E PERSISTÊNCIA)

1. Cadastro e Entrada de Novos Produtos:
- Descrição: Como funcionário responsável pelo Estoque, eu quero cadastrar novos produtos no sistema e atualizar a quantidade de itens recebidos, para que o setor de Vendas saiba o que está disponível.
- Critérios de Validação: O sistema não pode aceitar o cadastro sem nome, código (ID) e preço válido; a quantidade nunca pode ser negativa; se o código já existir, o sistema deve apenas somar a quantidade.

2. Salvamento e Recuperação de Dados:
- Descrição: Como administrador do sistema, eu quero que todos os dados (estoque, veículos e clientes) sejam salvos em arquivos ao fechar o programa e carregados ao abrir, para não perder informações.
- Critérios de Validação: O sistema deve criar um arquivo automaticamente se for a primeira vez; adições de novos clientes/produtos devem refletir no arquivo; o programa não pode fechar com erro se o arquivo estiver vazio.
