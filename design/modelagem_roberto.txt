1.Sistema de Gerenciamento de Clientes
*Descrição: Como Costumer Manager, eu quero cadastrar clientes usando o nome, o CPF e o email, para que eu possa associar as vendas a uma pessoa específica e gerar um histórico de compras.
*Criterios de aceitação:
    Deve ser possivel cadastrar um cliente utilizando seu Nome, email e CPF

    O sistema deve permitir a alteração do email e nome do cliente caso ele queira trocar de conta.

    O sistema deve validar suas informações como email e CPF de forma que contemplem formatos reais

    O sistema não deve permitir mais de uma pessoa possuir o mesmo email ou cpf.


2.Título: Sistema de Gerenciamento de Vendedores 
*Descrição: Como gerente de vendedores eu quero ter controle das vendas e dos vendedores
*Criterios de aceitação:    
	
    Visualizar todos os vendedores

    Viualizar dados de relacionados as vendas

    Poder filtrar esses dados para ter diferentes vizualizações

3.Título: Sistema do Cliente
*Descrição: Como cliente quero poder acessar os dados da minha conta, acompanhar minhas compras e fazer avaliações dos meus produtos e dos vendedores.
*Criterios de aceitação:

    Visualizar e editar o carrinho de compras

    Visualizar meu Histórico de compras

    Vizualizar e modificar meus dados de cadastro

    Avaliar as compras e vendedores

4.Título: Gerente
*Descrição: Como Gerente que aprovar descontos acima do limite que o vendedor normal consegue
*Criterios para aceitação:

    Verifica se o desconto que o cliente pede é maior que o limite que eu disponibilizo
